## ⚡ Особливості:
- **Уникнення дублікатів:** друзі можуть забронювати вибрану позицію, щоб інші бачили статус «Зайнято».
- **Прямі посилання на магазини:** Rozetka, Prom, Stall, Shopokit тощо.
- **Фільтри за категоріями:** Інструменти, EDC & Мультитули, Стиль, Антистрес, Побут.
- **Живий пошук та підрахунок:** моментальне відсіювання вільних та зайнятих подарунків.
- **Сучасний кібер-дизайн:** Glassmorphism, адаптивність під смартфони, плавні анімації.

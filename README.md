# 🎁 Boryslav Derkachov's Interactive Wishlist

Офіційний інтерактивний веб-портал вишлиста **Борислава Деркачова**.

🌐 **Live Demo (GitHub Pages):** [https://brslvdrkchv.github.io/wishlist/](https://brslvdrkchv.github.io/wishlist/)

---

## ⚡ Особливості:
- **Хмарна синхронізація в реальному часі:** друзі бачать актуальні статуси броней («Вільний» / «Зайнято») з будь-якого пристрою та браузера без скидання даних.
- **Підтримка бекендів:** працює одразу "з коробки" через хмарну базу, а також легко підключається до особистої Google Таблиці через `google_apps_script.js`.
- **Уникнення дублікатів:** друзі бронюють позицію в 1 клік, уникнувши однакових подарунків.
- **Прямі посилання на магазини:** Rozetka, Prom, Stall, Shopokit тощо.
- **Фільтри за категоріями:** Інструменти, EDC & Мультитули, Стиль, Антистрес.
- **Сучасний кібер-дизайн:** Glassmorphism, оптимізація під мобільні екрани, плавні анімації.

## 📊 Як підключити власну Google Таблицю (опціонально):
Якщо ви хочете, щоб усі бронювання падали у вашу власну Google Таблицю на Google Диску:
1. Відкрийте [Google Таблиці](https://sheets.new) та створіть нову таблицю.
2. Оберіть **Розширення (Extensions)** -> **Apps Script**.
3. Скопіюйте вміст файлу `google_apps_script.js` у редактор скриптів.
4. Натисніть **Deploy (Почати розгортання)** -> **New deployment (Нове розгортання)** -> тип **Web app (Веб-додаток)**.
5. Налаштування: *Execute as: Me*, *Who has access: Anyone*.
6. Скопіюйте URL веб-додатка та вставте його в `index.html` у конфіг `BACKEND_CONFIG` (поле `googleSheetsUrl` та тип `'google_sheets'`).
